# Shipped TweetNaCl deterministic primitives

The `wa-bundle:tweetnacl-deterministic` suite invokes the original shipped `tweetnacl` wrapper and `tweetnacl-1.0.3` implementation inside the behavior worker. No stub, host crypto provider, `self` alias, callback or PRNG is supplied. The original 14 cases retain their 397 probes per source revision unchanged. Version2 appends four hash cases and 78 probes, for 18 cases and 475 probes, with at most 64 probes per case. The focused archived run passed 19 tests and 18 unchanged comparisons across both pinned revisions. A private observer captured 36 full records before assertions, covering 54 source executions and 1,425 probe executions. All 24 frozen files matched before and after; the four added cases account for 12 executions and 234 probes including repeats. This is diagnostic process source evidence (isolated:false), separate from clean-checkout primary receipts and production execution.

Independent expected bytes come from the [NIST SHA-512 worked example](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Standards-and-Guidelines/documents/examples/SHA512.pdf), [RFC7748 section6.1](https://www.rfc-editor.org/rfc/rfc7748.html#section-6.1), [RFC8032 section7.1 test1](https://www.rfc-editor.org/rfc/rfc8032.html#section-7.1), and pinned libsodium [box](https://github.com/jedisct1/libsodium/blob/f0166d33e3a67d5d9b90999d738ba926e8e7a59a/test/default/box.c) and [secretbox](https://github.com/jedisct1/libsodium/blob/f0166d33e3a67d5d9b90999d738ba926e8e7a59a/test/default/secretbox.c) vectors. Metadata records exact upstream file hashes. For high-level NaCl operations, the C vector's 32 leading zero message bytes are removed; the first printed ciphertext copy already omits the 16 leading zero output bytes. Vector data is reused; no upstream library code is copied or executed by this suite.

The cases cover SHA-512, X25519 public keys/shared secrets, deterministic Ed25519 seeded keys/signatures/verification, and NaCl box/secretbox encryption and opening. Additional SHA-512 expectations are computed with host `node:crypto` outside the worker. Only typed JSON byte inputs and expected bytes enter the realm. Three fixed input profiles cover block boundaries and larger inputs: the largest zero input is 65,537 bytes; the other profiles stop at 32,769 bytes to preserve the existing 256KiB serialized-case limit. Earlier oversized input cases failed admission and were retained privately; they were not cryptographic failures.

The appended SHA-512 cases target the exact padding cutoff at remainder112: lengths110–114,239–241 and367–369 across the three original profiles. Existing127/128 cases already exercise both padding branches; the additions characterize their missing adjacent cutoffs. Separate visible-view cases use offsets1/7 and nonempty prefix/suffix sentinels, including empty views. Seven new invalid input types are each followed by the unchanged literal abc KAT in the same module scenario. A final alternating0xa5/0x5a profile covers16383/16384/16385-byte neighbors. Independent host Node SHA-512 supplies generated expected bytes; no primitive under test is replaced. The complete new cases serialize to34,621/27,543/3,711/173,266 bytes, below the unchanged256KiB limit; all existing14 full plans and oracles match their frozen prefix hash exactly. Offset checks make no backing mutation-isolation claim, and larger cases do not establish streaming or exhaustive message-length coverage.

Tamper tests flip one bit at each byte position in the published secretbox ciphertext, key and nonce, and the Ed25519 signature and public key. Other cases check short inputs, argument guards and offset byte views. These bounded checks do not cover every bit pattern, key, message or malformed signature. Random key generation, entropy, PRNG behavior and missing-PRNG exceptions are not tested.

Both original source modules are pinned for each revision. Default AST analysis remains blocked at its unchanged 2,000,000-work limit while traversing the implementation. Historical prose recorded 1,999,986 units; the current retained analyzer-v5 inventory records 1,999,990. No larger budget or selective function-only inventory closes that gap. The inventory remains incomplete. No zero-gate, empty-product or full configuration claim follows from an empty observed gate list.

This suite establishes bounded behavior of shipped bundled primitives. It does not establish the missing `cr:8712` binding, `WACryptoDependencies`, WhatsApp crypto providers, Signal/Noise/ratchet behavior, strict canonical signature handling, constant-time behavior or cryptographic security. Browser/bootstrap integration, container isolation, production suite scheduling, accounts/network and named-library adapter compliance remain unproven.

Run portable checks with `bun test tests/bundled-nacl.test.ts`. Actual implementation execution requires a reviewed adapter advertising the capability above. Diagnostic process runs report `isolated:false`.
